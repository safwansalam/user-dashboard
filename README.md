# User Dashboard (React Project)

## 📌 Project Overview
This is a React-based Admin Dashboard that displays a list of users fetched from a public API. It includes search, pagination, and user detail view.

---

## 🚀 Features
- Fetch users from public API
- Display users in responsive card layout
- Search users (with debouncing)
- Pagination (Next / Prev)
- View user details in modal
- Loading spinner
- Error handling UI

---

## 🛠️ Tech Stack
- React (useState, useEffect)
- Bootstrap (UI styling)
- JavaScript (ES6)

---

## ⚙️ State Management
I used React's built-in state management (`useState` and `useEffect`) because:
- Simple and sufficient for this project
- Avoids unnecessary complexity
- Easy to maintain and understand
